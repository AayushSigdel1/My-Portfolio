AAYUSH SIGDEL — PORTFOLIO WEBSITE

Files
- index.html: page structure and CV content
- style.css: responsive styling and visual design
- script.js: mobile navigation, scroll reveals, active navigation and image fallback
- Aayush_Sigdel_CV.pdf: downloadable CV

ADD YOUR PROFILE PHOTO
1. Copy your profile photo into this same folder.
2. Rename it exactly: profile.jpg
   (If it is PNG, either convert it to JPG or change the image filename in index.html.)
3. Open index.html in a browser.

RUN LOCALLY
You can double-click index.html to preview it. For a local development server, open this folder in VS Code and use the Live Server extension.

CUSTOMIZE
- Update contact details and text in index.html.
- Change colors near the top of style.css in the :root section.
- No build tools or package installation are required.
